# Fixes for #4471's two causes

## #1 — parser reads month-first

The shared date parser now reads a date in the order the tenant's own locale uses
(`dayFirst(tenant.locale)`, already computed in `causes.ts`), instead of a hardcoded
month-first order. Closes #1.

## #2 — wrong hint on booking-v3

`booking-v3`'s date field now prints the hint that matches the tenant's actual
locale order instead of a fixed `MM/DD/YYYY`, the same lookup `causes.ts`'s
`DATE_HINT`/`dayFirst` already does. Closes #2.
